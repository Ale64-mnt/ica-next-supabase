# Política de Privacidad

**Última actualización:** 1 de enero de 2026

La presente Política de Privacidad describe las políticas y procedimientos relativos a la recopilación, el uso y la divulgación de la información cuando utilizas el Sitio Web, así como tus derechos en materia de protección de datos personales y cómo la ley te protege.

El Sitio Web tiene una finalidad exclusivamente informativa y **no recopila activamente Datos Personales** de los usuarios.

Al utilizar el Sitio Web, reconoces esta Política de Privacidad.

Para obtener información sobre el uso de cookies y la gestión del consentimiento, consulta nuestra **Política de Cookies**.

## Recopilación y uso de los Datos Personales

### Tipos de Datos recopilados

#### Datos Personales

El Sitio Web **no recopila directamente Datos Personales** de los usuarios.

El Sitio Web no incluye:
- formularios de contacto,
- sistemas de registro,
- boletines informativos,
- cuentas de usuario,
- secciones de comentarios ni funciones interactivas que requieran el envío de Datos Personales.

En consecuencia, **no se solicitan ni recopilan** datos como:
- dirección de correo electrónico,
- nombre y apellidos.

#### Datos de uso

El Sitio Web **no recopila activamente Datos de Uso** con fines de análisis, elaboración de perfiles o seguimiento.

Ciertos datos técnicos (por ejemplo, dirección IP, información del navegador, marcas de tiempo o registros del servidor) pueden ser tratados **automáticamente por el proveedor de alojamiento** exclusivamente con fines de seguridad, funcionamiento y mantenimiento del Sitio Web.

Dichos datos **no son utilizados por el Responsable** para identificar a los usuarios, supervisar la navegación ni realizar actividades de elaboración de perfiles.

#### Tecnologías de seguimiento y Cookies

El Sitio Web utiliza una plataforma de gestión del consentimiento (**Cookiebot by Usercentrics**) para gestionar cookies y tecnologías similares.

Las cookies utilizadas en el Sitio Web se limitan a:
- **Cookies estrictamente necesarias**, esenciales para el correcto funcionamiento y la seguridad del Sitio Web;
- **Cookies de preferencias** (por ejemplo, configuración de idioma), que solo pueden activarse previo consentimiento del usuario a través del banner de Cookiebot, cuando corresponda.

No se utilizan cookies de análisis, marketing ni elaboración de perfiles, salvo que el usuario las active explícitamente mediante el banner de consentimiento.

El usuario puede gestionar o retirar su consentimiento en cualquier momento a través de los controles de Cookiebot disponibles en el Sitio Web (por ejemplo, “Gestionar cookies”).

## Uso de los Datos Personales

El Sitio Web **no utiliza Datos Personales** para:
- registro o gestión de cuentas,
- fines contractuales,
- marketing o promoción,
- análisis estadísticos,
- elaboración de perfiles,
- contacto directo con los usuarios.

No se realizan decisiones automatizadas ni actividades de elaboración de perfiles.

---

## Compartición de los Datos Personales

El Responsable **no comparte Datos Personales** con terceros, proveedores de servicios, socios comerciales u otros usuarios, ya que el Sitio Web no recopila Datos Personales.

La divulgación de Datos Personales solo puede producirse cuando así lo exija la ley o una solicitud válida de una autoridad pública competente.

---

## Conservación de los Datos Personales

El Sitio Web **no conserva Datos Personales** de los usuarios.

Cualquier registro técnico generado por el funcionamiento normal del Sitio Web es tratado exclusivamente por el proveedor de alojamiento y se conserva únicamente durante el tiempo estrictamente necesario, de conformidad con la legislación aplicable.

El Responsable no accede ni utiliza dichos datos con fines de análisis o elaboración de perfiles.

---

## Transferencia de los Datos Personales

El Sitio Web no realiza transferencias de Datos Personales a otros países o jurisdicciones.

Los datos técnicos que puedan ser tratados por el proveedor de alojamiento pueden almacenarse en servidores situados dentro o fuera de la Unión Europea, de conformidad con las garantías previstas por la normativa de protección de datos aplicable.

---

## Eliminación de los Datos Personales

Dado que el Sitio Web no recopila ni conserva Datos Personales, no existen cuentas ni perfiles de usuario que puedan eliminarse.

Si consideras que se han transmitido Datos Personales al Responsable por error, puedes ponerte en contacto con nosotros en **privacy@eduethica.eu** para las comprobaciones oportunas.

---

## Seguridad de los Datos Personales

La seguridad de los Datos Personales es importante para nosotros; sin embargo, ningún método de transmisión o almacenamiento electrónico es completamente seguro. Adoptamos medidas técnicas y organizativas adecuadas, pero no podemos garantizar una seguridad absoluta.

---

## Derechos del Interesado (GDPR)

Como Interesado, tienes derecho a:
- acceder a tus Datos Personales,
- solicitar su rectificación o supresión,
- oponerte al tratamiento,
- retirar el consentimiento, cuando sea aplicable,
- presentar una reclamación ante la Autoridad de Protección de Datos competente.

Puedes ejercer tus derechos contactándonos en **privacy@eduethica.eu**.

## Privacidad de los menores

El Sitio Web no recopila activamente Datos Personales, incluidos los de menores.

Los contenidos son de carácter informativo y educativo y no incluyen funciones que requieran el envío de Datos Personales.

No se realizan actividades de marketing ni elaboración de perfiles dirigidas a menores.

El Sitio Web puede contener enlaces a sitios web de terceros. No somos responsables del contenido ni de las políticas de privacidad de dichos sitios, y recomendamos revisar sus respectivas políticas.
